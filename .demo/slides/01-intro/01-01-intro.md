# Building Agentic Systems for production is hard

- **Long-Running processes**: Multi-step workflows that need guardrails
- **Orchestrate multiple LLM calls**: Multiple AI services need to work together reliably
- **State inconsistency**: Agent crashes mid-conversation → lost context
- **Reliability challenges**: When to retry? How many times? What state to preserve?
