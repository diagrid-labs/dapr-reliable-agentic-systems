## Introducing Conversation API

### New Building Block in Dapr

Unified interface for LLM providers

### Key Features

- **Multi-Provider Support** - OpenAI, Azure OpenAI, Anthropic, etc.
- **Consistent Programming Model** - Same code, different providers
- **Easy to Switch** - Change providers without code changes
- **Built-in Resilience** - Retry policies and circuit breakers
- **Provider Abstraction** - Focus on your logic, not provider details

### Why It Matters

Avoid vendor lock-in and simplify LLM integration
