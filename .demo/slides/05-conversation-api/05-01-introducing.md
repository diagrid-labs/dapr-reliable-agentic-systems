## Dapr Conversation API

Unified interface for LLM providers

### Key Features

- Abstraction over LLM providers
- Built-in Prompt Caching
- Built-in PII scrubbing
- Built-in Resilience

Supported LLM providers: OpenAI, Google AI, AWS Bedrock, HuggingFace, Anthropic, Mistral, DeepSeek, and Ollama.
